# 🔮 Tarot Reader — Claude skill ดูดวงไพ่ยิปซี

Agent skill สำหรับ Claude (Claude Code และ agent ที่รองรับ Agent Skills) ที่ทำให้ Claude อ่านไพ่ทาโรต์ได้ครบทุกรูปแบบ ถามข้อมูลประกอบก่อนทำนาย และให้ผู้ใช้สับ ตัด จั่วไพ่ด้วยมือตัวเองบนโต๊ะไพ่สไตล์คอมิก แล้วส่งผลกลับมาแปลผลอัตโนมัติ

## ความสามารถ

- **ไพ่ครบ 78 ใบ** Major และ Minor Arcana ทั้งหัวตั้งและกลับหัว แยกความหมายด้านความรัก งาน เงิน ใจ พร้อมธาตุ โหราศาสตร์ และแนวโน้มใช่/ไม่ใช่
- **29 รูปแบบการวางไพ่** จากไพ่ใบเดียวถึง Celtic Cross, ความสัมพันธ์, คืนดี, เลือกทาง A/B, ดวงรายปี 13 ใบ, 12 ภพ, จักระ, shadow work และกำหนดจำนวนใบเอง
- **ถามก่อนทำนาย** เช่น สถานะความรักตอนนี้ สถานะงาน หรือตัวเลือกที่ลังเล เพื่อให้คำทำนายตรงกับเรื่องจริงของผู้ถาม
- **ผู้ใช้สับ ตัด จั่วเอง** 5 โหมด: โต๊ะไพ่ HTML, ไพ่จริง, สำรับเสมือนในแชท, เลือกเลข, และสุ่มด่วน
- **โต๊ะไพ่สไตล์คอมิก + กระดาษ** เลือกหมวด → เลือกแบบ → ตั้งคำถาม → สับ (มีอนิเมชันแยกตามวิธีสับ) → ตัด → จั่ว → เปิดไพ่ รองรับมือถือและ dark mode ไฟล์เดียว ไม่ต้องติดตั้ง
- **ไร้รอยต่อ** ผลการจั่วกลับมาหา agent เองแล้วแปลผลทันที ทั้งผ่านเซิร์ฟเวอร์บนเครื่อง และผ่านลิงก์ claude.ai (Artifact)
- **เทคนิคขั้นสูง** ไพ่กลับหัว 5 มุมมอง, Elemental Dignities, ตัวเลข, Court cards, คู่ไพ่, การทำนายเวลา, ไพ่ประจำตัวและไพ่ประจำปี
- **ปลอดภัย** ไม่ทำนายความตาย ไม่วินิจฉัยโรค ไม่ฟันธงการลงทุนหรือคดี และมีสายด่วนเมื่อผู้ใช้อยู่ในภาวะวิกฤต

## ติดตั้ง

### ด้วย npx (แนะนำ)

ใช้ [Skills CLI](https://skills.sh/) ติดตั้งจาก GitHub ได้เลย รองรับ Claude Code, Codex, Cursor, GitHub Copilot และ agent อื่นอีกหลายตัว

ติดตั้งให้ใช้ได้ทุกโปรเจกต์:

```bash
npx skills add ChavaphonBoonchan/tarot_reader -g
```

หรือเฉพาะโปรเจกต์ปัจจุบัน:

```bash
npx skills add ChavaphonBoonchan/tarot_reader
```

อัปเดตเป็นเวอร์ชันล่าสุด:

```bash
npx skills update
```

### ด้วย git clone

ติดตั้งสำหรับทุกโปรเจกต์ (Claude Code):

```bash
git clone https://github.com/ChavaphonBoonchan/tarot_reader.git ~/.claude/skills/tarot-reading
```

หรือเฉพาะโปรเจกต์:

```bash
git clone https://github.com/ChavaphonBoonchan/tarot_reader.git .claude/skills/tarot-reading
```

ติดตั้งแล้วเริ่ม session ใหม่ ต้องมี `python3` (ใช้แค่ library มาตรฐาน)

## วิธีใช้

พิมพ์คุยตามปกติ skill จะทำงานเอง เช่น

- "ดูดวงความรักให้หน่อย"
- "ขอไพ่ประจำวัน"
- "ควรย้ายงานไหม ช่วยเปิดไพ่ให้หน่อย"
- "ไพ่ประจำตัวของคนเกิด 17/08/2538 คือใบไหน"

หรือเรียกตรง ๆ ด้วย `/tarot-reading` ถ้าวางข้อความที่ขึ้นต้นด้วย "🔮 ผลการจั่วไพ่จากโต๊ะไพ่ทาโรต์" agent จะแปลผลให้ทันที

## โครงสร้าง

```
SKILL.md                    workflow หลักของ agent
references/                 ความหมายไพ่ 78 ใบ, สเปรด, คำถาม intake, เทคนิค, จริยธรรม, รูปแบบคำทำนาย
scripts/table_server.py     เปิดโต๊ะไพ่บน localhost แล้วรับผลกลับมาให้ agent อัตโนมัติ
scripts/deck.py             สำรับเสมือนที่ผู้ใช้สับ/ตัด/จั่วเองผ่านคำสั่ง
scripts/birth_card.py       ไพ่ประจำตัวและไพ่ประจำปี
assets/tarot-table.html     โต๊ะไพ่ interactive
assets/spreads.json         ตำแหน่งของทุกสเปรด
```
